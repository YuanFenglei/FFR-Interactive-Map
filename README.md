# FFR交互式地图

FF共鸣离线收集地图：查看地图、宝箱与石板碎片，并在浏览器本地读取存档核对收集进度。

## 下载与使用

1. 下载[完整工具包](outputs/FFRS收集地图.zip)，然后解压。
2. 用 Edge 或 Chrome 打开[共鸣收集地图.html](outputs/FFRS收集地图/共鸣收集地图.html)。该 HTML 为独立文件，也可以单独下载使用。
3. 不选择存档即可浏览地图；选择自己的 GameSaveData*.sav 后可核对收集状态。

完整操作、数据口径与限制见[使用说明](outputs/FFRS收集地图/使用说明.md)。

## 内容

- 独立离线地图网页和 ZIP 工具包。
- [可读源码](outputs/FFRS收集地图/source/)：存档解析、界面代码、样式及点位元数据。
- 99 个石板碎片对象、233 个可收集宝箱对象、391 张地图分区图片，数据基于 Steam build 24250053。

存档仅在浏览器内存中读取和解析，不上传、不改写，不操作 Steam 云同步。仓库不包含个人存档、私人核验数据或本机构建依赖。

## 来源与组件

地图、名称与点位来自游戏本体；来源说明与统计限制见[使用说明](outputs/FFRS收集地图/使用说明.md)。AES 实现使用 aes-js 3.1.2，其 MIT 许可证保留在[组件许可证](outputs/FFRS收集地图/source/aes-js-LICENSE.txt)。该组件许可证不代表游戏素材的许可。
