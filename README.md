# FFR交互式地图 · 共鸣冒险者手册

[越战、触发、无念无想的适用范围](docs/特技与越战越勇.md)。

地图、技能数值与配装攻略合为一个离线工具。无需安装依赖，无需启动游戏，无需联网。

## 下载与打开

下载[离线工具包](FFR共鸣手册.zip)并解压，用 Edge / Chrome 打开其中的 **index.html**。也可单独下载[index.html](index.html)；地图、头像、数值与代码均内嵌。GitHub 文件页显示源码，请下载后打开。

## 六个入口

1. **交互地图**：99个石板碎片、233个宝箱放置点、391张分区底图；地区与物品搜索、分区切换、缩放拖动、点位详情、收集状态筛选。
2. **技能速查**：26名幻兵及8名角色自身技能；原幻兵池含217个去重被动、233个可习得主动、26个共鸣。按名称、ID、幻兵、效果搜索，按来源和类别筛选，按AP / 威力 / 破防排序，查看完整参数和共享来源。
3. **技能排行**：理论上限、短战AP效率、条件收益、限伤与乘区速查，保留每项适用条件；附乘区示例计算器。
4. **拉斯韦尔配装**：第5章前可实现的105 AP / 5栏方案，与终盘170 AP / 5栏核心分别展示。勾选预设技能可比较AP与栏位；包含养成门槛、行动安排和替换条件。
5. **幻兵评价**：26名幻兵的DPS与辅助职责、核心技能、养成停点，支持搜索和职责筛选；附AP养成计算器。

6. **主动与角色**：DPS与辅助分开讨论；按角色自身、当前幻兵、继承候选三个池子查技能，调整MP储备与出手次数查看费用压力。详见[角色与幻兵配装攻略](docs/幻兵综合排名与AP养成规划.md)及[角色自身技能池](docs/角色自身技能池.md)。

## 数值与攻略口径

- 数据基于 Steam build **24250053**，整理日期2026-10-27。结论依据静态配置与原生结算核验，不冒充实战DPS或队列测试。
- 第5章前方案表示该阶段可实现的养成目标，须完成列出的解锁、觉醒和熟练要求；不代表无需养成即可装备。终盘目标单独列示。
- 主幻兵已习得熟练技自动生效，不占继承AP / 栏位；觉醒技能不能按原始配置费用随意继承。共享技能按ID合并。
- 威力为整招配置值，不能再乘段数；治疗、准备、特殊公式、共鸣不按原始威力直接比较DPS。
- A / B / P / PB / BF是阅读代号；同区加算，不同结算环节分别核算。DPS按伤害、破防及MP窗口比较，辅助按有效治疗、保护、覆盖和维护成本比较。

## 隐私

可选择自己的存档核对地图进度。文件仅在浏览器内存中解析，不上传、不写回、不缓存，不连接 Steam。刷新、关闭或清除进度即丢弃页面中的存档状态。网页CSP禁止网络连接；查询、攻略和配装不需要存档。

仓库不含个人存档、解密副本、账号、个人进度快照、私人核验记录或本机路径。公开构建仅依赖本仓库文件。

## 目录与构建

- [source](source/)：界面、地图逻辑、只读解析器、模板和AES组件。
