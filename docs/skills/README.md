**分类说明**：表中Ability保留原始枚举，不等于全部都是文案“特技”；武器附魔技另属MagicSword。[特技名单与越战计数](../特技与越战越勇.md)说明具体边界，其他被动须分别核验。

先看[乘区与公式](乘区与公式.md)，再按幻兵打开技能表。各表同时保留原文、补全后的说明、习得来源、装备费用、作用环节和效果参数。

覆盖26名幻兵，217个去重被动，233个觉醒/熟练直接授予的去重主动技能，另补每名幻兵的共鸣技能；共259个去重主动/共鸣技能。共享技能在所属幻兵页分别列出，不把敌方全部技能或召唤物内部招式混入可习得总数。

## 阅读口径

1. A、B、P、PB、BF是本文给已追踪结算入口起的阅读代号，不是游戏官方术语。普通伤害与破防分开计算。
2. “提升30%”指其所属加成项，不保证最终伤害相对当前配置再增加30%。同区已有加成时存在边际递减。
3. 源文中部分数字是占位符；已按对应效果参数替换。纯“提升”文案另补解释；未明确的含义保留原值和疑点。
4. 结论依据Steam build 24250053。原生代码为磁盘二进制只读反汇编，没有运行游戏、注入进程、修改客户端或存档。
5. 浮点epsilon、逐段取整、暴击/抗性/防御等不在简化乘区例子里，实际显示伤害可能有取整差异。
