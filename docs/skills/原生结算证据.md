# FF共鸣原生结算证据

[总索引](README.md) · [中文公式与限制](乘区与公式.md)

本页是磁盘文件只读反汇编证据。函数没有调试符号，中文标题是根据数据流赋予的解释名，不冒充源码函数名。地址为该二进制的首选虚拟地址，RVA=VA−0x140000000；后续游戏更新可能改变地址。

EXE SHA256：b8c588e46ebadbe37feca7bdf2da0ae63a8538099d14a53ec0c2241b086e5ffa

证据链：反射类名字串 → 类注册函数 → 构造函数写入的虚表 → 对应槽位回调 → 消费这些回调的汇总函数。不能只用效果英文名判断乘区。
