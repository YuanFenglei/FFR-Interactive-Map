# 共鸣收集地图

双击 **index.html**，用 Edge 或 Chrome 打开。工具是一个约 6 MB 的独立 HTML 文件，不需要安装 Python、运行服务器、启动游戏或联网。可以只把这个 HTML 文件复制到家里的电脑。

## 使用

1. 不加载存档也能查看游戏原生地图和全部已提取点位。
2. 点击“选择存档”，选择实际游玩的 `GameSaveData*.sav`。常见位置是 `%LOCALAPPDATA%\FFRS\Steam\数字账号\`。文件编号代表不同存档槽，请结合修改时间选择。
3. 左侧搜索地区或物品；选择地区后可以切换地图分区。
4. 勾选宝箱、石板碎片及状态筛选，控制显示哪些图标。
5. 滚轮缩放，拖动平移，点击图标或下方清单查看位置与物品。
6. 游戏再次保存后，重新选择该文件即可刷新进度。页面不会自动追踪文件或云同步。

## 只读承诺与实现

- 文件仅由浏览器的普通文件选择框读取，使用 `File.arrayBuffer()`；解密与解析全部在内存中完成。
- 没有文件写入、覆盖、上传、存档编辑、Steam 操作或游戏启动功能。
- 没有调用可写文件句柄接口；也没有网络请求接口。
- 网页的内容安全策略禁止网络连接，只允许内嵌脚本、样式和图片。
- 不会在浏览器本地存储中保存你的存档。关闭、刷新或点击“清除进度”会丢弃页面内的进度。
- 包内不含本机存档、解密存档或个人账号信息。

工具不修改游戏安装目录、原始存档目录或Steam云同步。

## 数据与统计口径

数据来自已安装的 Steam build **24250053**：

- 99 个石板碎片对象，物品 ID 为 25004。
- 233 个可收集宝箱放置对象，覆盖相关的 64 个地图编号。
- 391 张游戏原生地图分区图片。
- 排除了 10 个游戏本体中初始已经打开的装饰箱。
- 包含保险箱和剧情版本的地图。同名地区的不同地图编号分别显示，宝箱分母是放置对象数量，不等同于成就的分母。

位置来自对象的世界坐标，按游戏地图配置中的中心与范围映射到底图。石板与宝箱标签 `S1`、`B1` 是本工具的地区内编号，不是攻略编号。详情中的 UID 是游戏对象编号。

## 状态含义与限制

| 状态 | 含义 |
|---|---|
| 灰色 / 已获取 | 存档中存在对应地图编号与 UID，并明确记录已开启或拾取 |
| 亮色 / 未获取 | 存档存在对应记录，状态为未开启 |
| 亮色虚线 / 未记录 | 存档不存在对应记录，可能未进入、未拾取或版本变化；不是确定漏收的结论 |
| 预览 | 尚未加载存档，显示点位但不判断完成情况 |

石板还会核对持有数量与已交付数量之和。若与地图确认数量不一致，页面会提示，不会自行补齐或猜测具体点位。

多层地区存在平面坐标重叠。分区候选根据底图可见区域匹配，一个点可能出现在多个候选分区；请结合游戏画面与高度 Z 核对。少量位于地形边缘的点没有可靠分区归属，会在所有分区中保留并注明“分区归属待核对”。地图分区号不代表实际楼层名。

目前验证的存档封装为 SVHD v1、GVAS v3 / UE 5.6。游戏更新可能改变地图编号、UID、点位或存档结构。无法解析时会报错并保留之前的进度；对于旧地图编号，不会擅自与新地图合并。

## 验证情况

- 与 uesave 的解析结果交叉比对：所有地图宝箱记录、物品栏及交付记录一致。
- 在内存中验证 AES 解密互通；测试错误标记、版本、损坏密文和截断文件的拒绝处理。
- 验证读取前后的测试数据字节与工作副本哈希不变；测试没有访问原始存档。
- 地图中的已获取石板状态合计与独立的“持有＋交付”计数一致。
- 离线 DOM 测试覆盖全部 64 个地图与可选分区，所有使用的底图均内嵌；筛选、详情、缩放、加载、错误恢复与清除进度通过。
- 整合版已使用本地HTTP预览检查桌面界面；离线资源由构建校验覆盖。DOM检查与视觉检查分别记录在[验证说明](验证说明.md)。

[source](../source/) 中提供可读的解析代码、界面代码和点位元数据，便于检查只读实现。
