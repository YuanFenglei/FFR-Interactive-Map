## 先看结论

1. **综合优先关注蒂娜、萨菲罗斯、斯考尔；特伦和彩花分别补续航破防、治疗保护。** 这不是要求同一角色全部练满：萨菲罗斯的核心熟练1就有，蒂娜触顶时才需要突破极限9。
2. **示例养成规模为364 AP；26名全部熟练9为516 AP。** 两者均是单个角色的上限，不能把不同队员的熟练度合并计算。
3. **MASTER是一栏打包5个熟练技能，费用90～130 AP，不是固定105。** 觉醒、主幻兵招式与共鸣不随包跨幻兵继承；永久AP/属性奖励也不会再加一次。
4. **先排除当前主幻兵已习得的熟练能力：本体自动生效，不占AP和栏位。** 表内单技/MASTER费用用于跨幻兵继承；主幻兵不需要再装备自己的技能包。同ID不重复计收益。游戏教程条目Tutorial_AbilityEquipment_004为直接依据。
5. **AP不足时选单技，栏位不足时才比较打包。** 例如突破极限单装30 AP，蒂娜MASTER95 AP；只为突破而打包会额外花65 AP。

## AP总量：集合嵌套，不能重复计数

原版基础AP按100计算；MR表示熟练度。逐行核对26名幻兵配置：**MR4永久＋8、MR9再＋8；MR7/8没有AP奖励**。一般公式为“100＋8×达到MR4的幻兵数＋8×达到MR9的幻兵数”。

| 养成状态（同一角色） | MR4奖励 | MR9奖励 | 养成新增AP | 总AP上限 |
|---|---:|---:|---:|---:|
| 尚无上述奖励 | 0 | 0 | 0 | 100 |
| 26名都达到4，尚无9 | 26×8＝208 | 0 | 208 | 308 |
| 26名至少4，其中15名至少7，其中7名达到9 | 208 | 7×8＝56 | **264** | **364** |
| 26名全部9，极限情况 | 208 | 26×8＝208 | **416** | **516** |

指定规模展开为**11名MR4～6＋8名MR7～8＋7名MR9**；可用代表值11×MR4＋8×MR7＋7×MR9计算。15名里面包含那7名，不能再额外加15份AP。“平均4级”若仅指等级算术平均，不能保证每名都领到MR4奖励；上表按“26名全部至少4级”解释。

MR4累计需求通常195 MRP，诺克提斯/萨菲罗斯275；26名全部从0练到4合计5230 MRP，得到208 AP。全部从0练到9合计121360 MRP。两者是**各角色—幻兵组合所需累计点数之和，不是全队战斗次数或实际耗时**；MRP加成影响刷取时间。指定15/7的总MRP取决于选谁，不能只凭人数得到唯一值。

来源：熟练奖励表直接支持两档＋8和MRP。基础100现已由参数计算表的baseSkillEquipCost＝100直接确认；不再仅依赖外部说明。516是此26名、此原版奖励规则下的理论值，不外推到改动AP规则的模组。

## 排名策略：先过门槛，再评分

**门槛优先于分数**：单段已受9999限制时，先保留突破极限；否则其即时增伤为0。存活、必须解除的异常、治疗与保护同样先满足。对属性吸收能直接解决的敌人，该幻兵可越过通用榜上调。

总分＝5×关键性＋3×AP效率＋3×覆盖＋3×行动＋2×养成＋3×本体＋1×打包，满分100。每项0～5分；这是可调整的**策划评价分，不是实测DPS或百分比收益**。继承相关项占85分，主幻兵本体占15分；看主幻兵请再看下方分工表。5分表示突出，3分表示有明确用途，1分表示窄场景，0分表示无有效贡献，2/4为中间档。

| 项目 / 满分 | 具体判断口径 |
|---|---|
| 关键性 / 25 | 5＝限伤等无法用普通增伤替代的门槛；4＝双指令、独特高效乘区或长期养成加速；3＝职责核心；2＝可替代的条件强化；1＝偏经济或窄用途。突破极限5分以触顶输出需求存在为前提。 |
| AP效率 / 15 | 看有用核心技能的净收益/AP，而非整套标称之和；15～20 AP的强增益易得高分；双动虽贵，能完成两个有效动作仍可高分。负面MP、无效包内技能扣分。 |
| 覆盖 / 15 | 在适配职责内考察3次短窗口与6次持续窗口：5＝核心自然覆盖大部分有效动作；3＝依赖破防/追加/暴击等窗口；1＝罕见触发。不是全职业通用率，不预送多重buff、低血或多异常。 |
| 行动 / 15 | 5＝无额外准备、压缩必需动作或减少维护；3＝有维持、顺序或供给代价；1＝需要频繁专门准备。延长必要buff有效，替输出强铺无用buff无效。 |
| 养成 / 10 | 按该行主评分核心取得点：MR1～3为5，MR5为4，MR7为3，MR9累计≤4500为2，超过4500为1。不是整名幻兵所有技能都容易刷；9级目标必须单列判断。 |
| 本体 / 15 | 结合觉醒、主动招式、共鸣对该职责的贡献；5＝该职责优先候选，3＝流派/敌人适配，1＝有更直接替代。不把觉醒技能原始费用当继承AP。 |
| 打包 / 5 | 5＝常用核心合计已到包价且能省多栏；4＝少量加AP换多栏；3＝专门构筑能利用；1＝主要只需一两技或含显著副作用。以本表实用核心组合判断，不按“全5技折扣最大”排序。 |

评分核心：蒂娜按突破极限9，香托托按连续咏唱9，弗利奥尼尔按W臂腕9，克劳德按暴击增幅9，洋葱剑士按三重蓄力9；其他按表内首个关键技能。萨菲罗斯虽然MASTER最贵，单拿无念无想反而很早且便宜。维多利亚如尚有大量幻兵待练，可先于战斗总分更高者练7，以降低后续训练耗时。

## MR9怎么选，回合怎么分

1. **触顶输出先蒂娜9**；未触顶时不把30 AP当即时增伤。单次解锁收益为min(d,99999)－min(d,9999)，多段按实际受限段比较。解锁上限不等于伤害直接十倍。
2. **按角色选双行动**：特技手优先斯考尔9（50 AP）；黑白魔法手/治疗者优先香托托9（50 AP）；确需更广指令组合时比较弗利奥尼尔9（60 AP，指令本身40 MP）。W行动与连续咏唱指令本身配置0 MP，但里面选择的技能仍要付费；不能把双动当无MP代价。
3. **其余9级名额按瓶颈选**：高耗角色特伦；高暴击角色克劳德；极限体系洋葱剑士/彩花；模仿体系巴兹；坦克致命伤容错光之战士；特定属性Boss选对应吸收。没有必要让所有角色用同一套7名，也不为凑7名去刷用不到的包。
4. **先铺4、再挑5/7、最后专攻9**是默认养成顺序；硬门槛可以插队。维多利亚7的MRP1.5倍适合剩余养成多时提早投入，但装备它的30 AP/1栏也有战斗机会成本。追加到9只为再拿8 AP时，优先比较仍未拿过MR4的幻兵。
5. **输出、弱化、治疗保护分工**：常规输出每轮先按1次主行动算；双动只在指令允许范围内计2次；触发追加才另加。弱化交给本来承担控制的队员，治疗者先安排治疗/护盾，靠延长必要状态减少维护；不把全部增益挤给一个人，也不要求奶妈为状态极好凑数。
6. **托付机会是转移，不是创造全队行动**：莉亚熟练5单装30 AP，实际使用25 MP；其价值是让更合适的人执行关键动作，须扣掉给予者原本能做的治疗/保护。急速改变顺序，多段不自动等于多次出手，叠层次数不按视觉段数猜。
