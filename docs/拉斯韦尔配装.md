# 拉斯韦尔配装：第5章前与终盘

[返回手册](../README.md) · [技能数值表](skills/README.md)

依据Steam build 24250053；不计武器装备。各方案为完成所列养成后的目标，静态核验不等于实战测试。

## 第5章前：位移进攻 · 诺克提斯

主幻兵诺克提斯觉醒3；完成各项熟练要求后使用。第5章前可实现不等于无需养成，也不表示每份存档已具备全部技能。

主幻兵已习得熟练技自动生效：熟练3的看破、熟练7的追加伤害均无需继承AP或栏位。追加伤害尚未习得时不能提前计入；换主幻兵后继承费用为40 AP。

| 继承技能 | AP | 来源 | 用途 |
|---|---:|---|---|
| 触发 | 20 | 斯考尔 · 熟练5 | 普攻 / 特技，普通增伤A与破防B各＋30%。 |
| 越战越勇 | 20 | 斯考尔 · 熟练1 | 按有效攻击计数自然叠层，不把短战当作开场满50%。 |
| 状态极好 | 20 | 提达 · 熟练7 | 每种有效强化A＋15%，只计算自然存在的必要状态。 |
| 先下手为强 | 20 | 卡米尔 · 熟练3 | 只对本回合尚未行动的目标有效；经常后手时可撤。 |
| 破防恢复法力值 | 20 | 特伦 · 熟练1 | 由自己造成破防时恢复5% MP，不计队友破防。 |
| 平衡崩坏 | 15 | 提达 · 熟练5 | 主动指令也占栏；强化所选物理攻击的破防并增加MP消耗。 |
| 突破极限 | 30 | 蒂娜 · 熟练9 | 伤害上限9999→99999。先完成蒂娜9的养成；未触顶时不直接增伤。 |

合计：145 AP / 7栏。

### 行动安排

- **日常省蓝：位移破击**。15 MP / 总威力33 / 基础破防19；直接进攻并争取追加机会。
- **输出窗口：位移突袭**。42 MP / 总威力56 / 基础破防25；5段分配总威力，不能再乘5。
- **抢破防：平衡崩坏 → 所选物理攻击**。按剩余破防槽决定；敌人已破防时不为普通伤害盲用。
- **获得追加：继续有效攻击**。只计实际得到的机会；位移概率存在文案冲突，不承诺稳定双动。

### 养成顺序

1. 蒂娜9：输出触顶时优先取得突破极限，是本方案的高等级养成投入。
2. 斯考尔5：途中取得越战越勇，再拿触发。
3. 卡米尔3：仅在抢先攻击有覆盖时使用先下手为强。
4. 提达7、特伦1、诺克提斯7：按所列来源补齐；诺克提斯7奖励本体免费生效。

### 条件与替换

- 基础套145 AP / 7栏。200 AP容量时也不必装满；暴击覆盖且突破后有收益时，可加暴击增幅40，成为185 AP / 8栏。
- 经常后手可撤先下手为强，降至125 AP / 6栏；很少亲自破防时，回蓝项可换卡米尔熟练1的受伤害时恢复法力值20。
- 位移技为光属性；遇抗光或吸收光敌人须换适用招式。敏锐不强化诺克提斯位移招式。
- 仅计本体20%＋勇气50%＋触发30%＋一种强化15%时，A系数2.15；同区相加，不能逐项相乘。

## 终盘规划：明镜连击 · 萨菲罗斯

萨菲罗斯觉醒4、熟练至少1；蒂娜 / 斯考尔 / 弗利奥尼尔 / 特伦须完成对应9级目标。本页终盘方案不属于第5章前方案。

主萨菲罗斯已习得的无念无想（熟练1）自动生效，提供P＋50%，不占20 AP / 1栏。角色固有敏锐（Lv5，8 MP）与明镜止水（Lv25，25 MP）也不占继承AP。

| 继承技能 | AP | 来源 | 用途 |
|---|---:|---|---|
| 斯考尔MASTER | 105 | 斯考尔 · 熟练9 | W行动＋触发＋越战越勇等熟练技一栏打包；不再重复单装。 |
| W臂腕 | 60 | 弗利奥尼尔 · 熟练9 | 一轮双准备，或选择两组W行动形成四次攻击；仍支付各指令MP。 |
| 突破极限 | 30 | 蒂娜 · 熟练9 | 保留限伤位置，尤其极·明镜的单段输出。 |
| 破防恢复法力值 | 20 | 特伦 · 熟练1 | 可选续航位；移除此项即300 AP / 7栏基本套。 |
| 法力值消耗减半 | 50 | 特伦 · 熟练9 | 支撑双动与四动，避免补MP行动吞掉输出收益。 |
| 聚焦之理 | 20 | 蒂娜 · 熟练7 | 敌人仅1名时，全体攻击A＋100%；单体招式不适用。 |
| 状态极好 | 20 | 提达 · 熟练7 | 勇气、敏锐、迅速自然覆盖时A＋45%；不虚算第4种强化。 |
| 平衡崩坏 | 15 | 提达 · 熟练5 | 按需求强化所选攻击；不能假定一次指令覆盖全部四击。 |

合计：320 AP / 8栏。

### 行动安排

- **短战：W行动 → 双攻**。不强制先叠两项增益；能直接解决就直接攻击。
- **长Boss准备：W臂腕 → 敏锐＋明镜止水**。同轮完成两项准备，但本轮0次攻击；准备的机会成本必须计入。
- **折中准备：W臂腕 → 敏锐＋W行动**。保留2次攻击；明镜止水按速度与破防需求再补。
- **有效爆发窗口：W臂腕 → 两组W行动**。共4次攻击。半耗下四极·明镜约156 MP，四破邪冰岚约180 MP；并非每轮免费四动。

### 养成顺序

1. 先蒂娜9取得突破；斯考尔先5后9，特伦9配套解决MP，弗利奥尼尔9再升级四动。
2. 萨菲罗斯熟练1取得无念无想，4级补AP即可；本方案不要求其9级。
3. AP＝100＋8×至少熟练4的人数＋8×熟练9的人数，按同一角色分别计算。
4. 19名至少4且其中6名9：300 AP；22名至少4且其中6名9：324 AP；26名至少4且其中6名9：356 AP。

### 条件与替换

- 主方案320 AP / 8栏；撤掉破防回蓝即300 AP / 7栏。不是必须凑到400 AP才毕业。
- 主攻参考：破邪冰岚80 MP / 总威力75 / 破防32；极·明镜68 / 80 / 45；明镜13 / 19 / 40。总威力不再乘段数。
- 敏锐只增强指定明镜系等招式；明镜止水速度＋50%、破防B＋40%，速度不直接多一次指令。
- 满准备A系数2.95，越战满层3.45；群技打单Boss加聚焦后3.95～4.45；P为1.50。仍须经过敌防、抗性、暴击与限伤。
- W臂腕与W行动组合已做配置和攻略交叉核验，未在本机执行实战队列测试；平衡崩坏嵌套覆盖不作确定承诺。

组合交叉依据：[GAME8神龙攻略](https://game8.jp/ffrs/836342)。数值与乘区详见[公式](skills/乘区与公式.md)。
