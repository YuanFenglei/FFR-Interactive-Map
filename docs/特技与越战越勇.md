# 特技、武器附魔技与越战越勇

[返回手册](../README.md) · [技能总表](skills/README.md)

## 分类与识别

“特技”不等于“武器附魔技”。武器附魔技属于MagicSword（魔法剑）；Ability是另一种更宽的内部分类，也不能整体翻译成文案特技。

对主动表的中文与日文说明分别搜索“特技”，两边都命中以下13项，恰好等于技能通用表normalAttackSkills去掉跳跃落地内部技400220。在当前版本，可看说明是否明确写出“特技”识别这组招式；实际计数按技能ID判断，不读取说明文字。

## 越战计数与已有增伤

1. 当前执行技能ID等于角色普通攻击ID，或在上述名单（含400220），正常结束后计数＋1。每个计数提供A/B各10%，5次后加成封顶50%。一招多段只计一次。
2. 插入辅助或名单外招式不新增计数，也不因换招清层。明镜、极·明镜、破邪冰岚、强行分离、位移破击和位移突袭均不能自行叠越战。
3. 新增计数与享受增伤是两件事。已有增伤回调只读计数，不再过滤当前技能；名单外招式在普通伤害/破防路径上仍可受益，固定伤害等特殊公式另看计算开关。
4. 常见物理/魔法反击实际使用400120/400130，不加层但可享受已有加成。指定技能反击须按实际ID判断。
5. 从0层连续平A，第1～6次享受0%、10%、20%、30%、40%、50%。等权3次平均10%，6次平均25%；这不是任意3次或6次攻击都有的收益。

## 两个W指令

| 指令 | 来源 / 继承AP | 指令自身MP | 用途 |
|---|---|---:|---|
| W臂腕 | 弗利奥尼尔熟练9 / 60 AP | 40 | 两条指令，可搭配辅助、攻击；有指定禁用项 |
| W行动 | 斯考尔熟练9 / 50 AP | 0 | 两次非黑白魔法攻击招式；不等于只限物理伤害 |

内部招式另付各自MP。两个W指令本身不计层，内部招式逐一判断：剑之舞＋剑之舞加2；强行分离＋强行分离、明镜＋明镜都加0。W臂腕可选两组W行动形成4次攻击，但四次明镜仍加0层；W臂腕不能套自身。跳跃启动和落地都有名单项，具体任务拆分未追完，不宣称一次跳跃必加2层。

## 证据与适用边界

配置来源：DT_SkillData的Name/Description/skillAttrType、DT_SkillGeneralData的normalAttackSkills及多动限制、DT_SkillEffectData的反击参数。原生计数过滤0x144FB8EC0，结束调用0x144F49B70，写入0x144F7E088；增伤回调0x145148240直接读取战斗计数。地址只适用于本页版本。

## 三项被动的适用范围

| 被动 | 适用范围 |
|---|---|
| 越战越勇 | 当前角色的平A或指定名单特技结束后计数＋1；每次A/B各＋10%，5次封顶50%。名单外招式不增加计数，但普通伤害/破防路径可享受已有增伤。辅助不清层，一招多段只计一次。 |
| 触发 | 当前招式为角色平A或指定名单特技时，A/B各＋30%。明镜、位移、强行分离、武器附魔技及常见普通反击不适用。 |
| 无念无想 | 当前招式为角色平A或指定名单特技时，基础威力P＋50%。明镜、位移、强行分离、武器附魔技及常见普通反击不适用。 |
