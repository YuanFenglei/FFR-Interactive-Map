# 8名角色自身技能池

[返回手册](../README.md) · [角色与幻兵配装攻略](幻兵综合排名与AP养成规划.md)

Steam build 24250053，2026-10-28。来自8张等级奖励表；补充普通攻击和已识别的非等级专属指令。等级不代表剧情已解锁；未核实的进度明确保留。自身技能不占继承AP/栏位。相同技能ID与幻兵池去重，不重复付费。

威力为整招原始配置，不能乘段数；极限技消耗极限槽，特殊条件技不能纳入日常续航。治疗威力、比例伤害与普通伤害公式不通用。原始破防字段不代表辅助技能会削减破防槽。
