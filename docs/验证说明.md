# 验证说明

数据版本：Steam build 24250053。

1. 数据与来源：26名幻兵原池476个技能；8名角色152条来源记录、151个ID，合并后580个技能条目。核对127条等级奖励、极限槽与特殊费用、跨池去重和继承资格。
2. 配装：第5章前105 AP / 5栏；终盘核心170 AP / 5栏。核对有效主招、继承费用、条件替换与扩展栏位；DPS和辅助按职责筛选，不使用跨职责综合分。
3. 页面回归：技能搜索、来源过滤、排序、分页、详情；被动收益表；配装预算和恢复预设；幻兵职责筛选、技能跳转；MP储备、出手次数、缺蓝提示、辅助治疗不进入伤害效率。
4. 地图：核对99个石板、233个宝箱、391张内嵌地图图片；回归64张地图及分区、点位筛选、清除进度和畸形输入拒绝。
5. 发布：核对Markdown链接、公开文件隐私边界、HTML资源内嵌、禁止联网与持久化、ZIP内容与成品一致。

数据检查：运行 python tests/verify.py。交互逻辑回归：安装jsdom 29.1.1后运行 node tests/ui.cjs。游戏数据与浏览器运行本身不需要Node.js或Python。

DOM回归不等于视觉验收。当前主动与角色页面未完成真实浏览器视觉验收；未执行游戏实战伤害、多动队列、真实存档解析或MP取整组合测试。
